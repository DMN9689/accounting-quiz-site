03 단기매매증권의 취득·처분·기말평가수업자료 p.16~19
단기매매증권은 취득수수료, 처분수수료, 기말평가의 처리방식이 서로 다릅니다.
단계핵심 처리손익
취득주식대금만 단기매매증권. 수수료는 별도 비용수수료비용(영업외비용)
처분수수료를 별도 수수료비용으로 쓰지 않고 처분손익에 반영처분이익 또는 처분손실
기말평가장부가액을 기말 공정가액으로 변경평가이익 또는 평가손실

처분 시 계산 순서

처분한 주식의 장부가액을 대변에서 소멸시킵니다.
실제 받은 금액 또는 지급한 수수료를 기록합니다.
마지막 대차차액을 처분이익 또는 처분손실로 맞춥니다.
평가 후 다음 연도 처분 시 장부가액 = 전기말 공정가액
문제에서 먼저 볼 말: 취득 / 처분 / 기말평가 / 전기말 공정가액 / 수수료 차감
