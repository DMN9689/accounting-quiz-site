# 분개 계정과목의 괄호 표기 — 질문과 답변

## 1. 사용자 질문

> 분개에서 `보험료`가 아닌 `보험료(판)`으로 기재해야 하잖아.  
> 이런 부분들도 헷갈리는데, 계정과목 뒤에 괄호를 붙이는지, 붙인다면 어떤 내용이 들어가는지 알고 싶다.

## 2. 핵심 답변

현재 상세 수업자료 기준으로는 계정과목 이름만 맞히는 것에 그치지 않고, 필요한 경우 **계정과목 뒤 괄호까지 표시**해야 한다.

다만 괄호에 들어가는 내용은 모두 같은 성격이 아니다. 먼저 아래 네 가지 중 어느 용도인지 구분해야 한다.

| 괄호의 용도 | 괄호 안에 들어가는 내용 | 예시 |
|---|---|---|
| 비용의 소속 구분 | `판`, `제`, `영` | `보험료(판)`, `복리후생비(제)`, `수수료비용(영)` |
| 채권·채무의 거래처 구분 | 거래처·은행·카드사·보험사명 | `외상매출금(미금)`, `미지급금(국민)`, `선급비용(현대)` |
| 대손충당금의 대상 채권 구분 | `외`, `받`, `미수`, `단기` 등 | `대손충당금(외)`, `대손충당금(받)` |
| 예수금의 세목 구분 | 원천징수한 세금·공과금 종류 | `예수금(근로소득세)`, `예수금(국민연금)` |

따라서 괄호를 볼 때는 다음 질문부터 해야 한다.

> 이 괄호는 **비용의 소속**, **거래처**, **대손 대상 채권**, **원천징수 세목** 중 무엇을 표시하는가?

# 3. 비용의 소속을 표시하는 괄호

## 3.1 `(판)` — 판매와관리비

본사, 영업부, 관리부 등에서 발생한 비용은 판매와관리비 800번대 코드로 구분하며 `(판)`을 붙인다.

```text
보험료(판)
복리후생비(판)
통신비(판)
수선비(판)
도서인쇄비(판)
운반비(판)
여비교통비(판)
임차료(판)
세금과공과(판)
수수료비용(판)
교육훈련비(판)
대손상각비(판)
```

### 예시

```text
본사 업무용 자동차보험료 480,000원을 현금으로 지급
보험료(판) 480,000 / 현금 480,000
```

```text
영업부 직원 간식 90,000원을 현금으로 구입
복리후생비(판) 90,000 / 현금 90,000
```

```text
본사 컴퓨터 수리비 150,000원을 보통예금으로 지급
수선비(판) 150,000 / 보통예금 150,000
```

## 3.2 `(제)` — 제조원가

공장, 생산부 등에서 발생한 비용은 제조원가 500번대 코드로 구분하며 `(제)`를 붙인다.

```text
보험료(제)
복리후생비(제)
세금과공과(제)
수수료비용(제)
교육훈련비(제)
```

### 예시

```text
공장 화물트럭 보험료 1,800,000원을 현금으로 지급
보험료(제) 1,800,000 / 현금 1,800,000
```

```text
생산부 직원 간식 50,000원을 현금으로 구입
복리후생비(제) 50,000 / 현금 50,000
```

```text
생산부 외부강사료 2,000,000원에서 사업소득세를 원천징수
교육훈련비(제) 2,000,000 / 보통예금 1,934,000
                                  예수금(사업소득세) 66,000
```

## 3.3 `(영)` — 영업외

영업과 관련 없이 발생한 900번대 수익·비용은 답안에서 `(영)`으로 줄여 표시할 수 있다.

수업자료에서는 설명용으로 `(영외비)` 또는 `(영외수)`라고 풀어서 표시하기도 한다.

```text
수수료비용(영)
기타의대손상각비(영)
대손충당금환입(영)
잡손실(영외비)
잡이익(영외수)
단기매매증권처분손실(영외비)
단기매매증권처분이익(영외수)
```

### 예시

```text
단기매매증권 취득수수료 150,000원 발생
수수료비용(영) 150,000 / 현금 150,000
```

# 4. 보험료에서 `(판)`과 `(제)`를 판단하는 방법

보험료는 다음 두 단계를 거쳐 판단한다.

## 4.1 먼저 보험료 계정인지 확인

차량과 관련된 지출이라고 모두 차량유지비는 아니다.

| 지출 내용 | 계정과목 |
|---|---|
| 차량 유류대 | 차량유지비 |
| 차량 수선비 | 차량유지비 |
| 주차요금 | 차량유지비 |
| 세차요금 | 차량유지비 |
| 자동차보험료 | 보험료 |
| 건물·비품·기계장치 보험료 | 보험료 |

## 4.2 그다음 발생 장소·부서를 확인

| 보험 대상 | 상세 답안 |
|---|---|
| 본사 업무용 승용차 | `보험료(판)` |
| 본사 건물 화재보험 | `보험료(판)` |
| 본사 비품 보험 | `보험료(판)` |
| 공장 화물트럭 | `보험료(제)` |
| 공장 건물 화재보험 | `보험료(제)` |
| 공장 기계장치 보험 | `보험료(제)` |

### 결산수정분개 예시

본사 보험의 미경과보험료를 이월하는 경우:

```text
선급비용(보험사) 800,000 / 보험료(판) 800,000
```

공장 보험의 미경과보험료를 이월하는 경우:

```text
선급비용(현대) 1,500,000 / 보험료(제) 1,500,000
```

여기서 두 괄호의 의미는 서로 다르다.

- `선급비용(보험사)` 또는 `선급비용(현대)`의 괄호: **거래처명**
- `보험료(판)` 또는 `보험료(제)`의 괄호: **비용의 소속**

# 5. 수수료비용은 세 가지 구분이 모두 가능

수업자료에서는 비용계정 중 `수수료비용`은 제조원가, 판매와관리비, 영업외비용의 세 구분이 모두 가능하다고 정리한다.

| 수수료 발생 원인 | 표기 |
|---|---|
| 공장·생산과 관련하여 발생 | `수수료비용(제)` |
| 본사·매출·판매관리와 관련하여 발생 | `수수료비용(판)` |
| 금융·투자 등 영업 외 활동에서 발생 | `수수료비용(영)` |

### 자료 속 대표 사례

```text
받을어음 만기추심수수료
수수료비용(판)
```

```text
단기매매증권 취득수수료
수수료비용(영)
```

```text
차입 시 공제된 금융수수료
수수료비용(영)
```

# 6. 기업업무추진비는 거래처 기준으로 구분

`기업업무추진비`는 일반적인 비용처럼 단순히 발생 장소만 보는 것이 아니라, **어느 거래처에 지출했는지**를 기준으로 구분한다.

| 지출 대상 | 표기 |
|---|---|
| 매출거래처 | `기업업무추진비(판)` |
| 매입거래처 | `기업업무추진비(제)` |

자료에서는 대부분 매출거래처 관련 지출이므로 `기업업무추진비(판)`이 주로 사용된다고 설명한다.

### 예시

```text
매출거래처 직원과 식사
기업업무추진비(판)
```

```text
매입거래처 방문 시 음료 제공
기업업무추진비(제)
```

> 확인 필요: 20260824 수업자료 30쪽의 한 예시에는 `기업업무추진비(재)`라고 적혀 있으나, 10쪽 기준표는 매입거래처 지출을 제조원가로 구분한다. Codex에서 해당 표기를 자동 수정하지 말고 원문 표기와 기준표의 차이를 별도 검토 대상으로 남긴다.

# 7. 거래처를 표시하는 괄호

수업자료에서는 채권과 채무를 거래처별로 관리하기 위해 거래처를 괄호 안에 기입한다.

## 7.1 대표 계정

```text
외상매출금(미금)
받을어음(서현)
미수금(죽전)
외상매입금(수원)
지급어음(죽전)
미지급금(삼보)
선급금(진사)
선수금(부산)
단기대여금(금성)
단기차입금(대림)
임차보증금(민지)
임대보증금(미금)
가지급금(김윤정)
가수금(김윤정)
선급비용(현대)
선수수익(죽전)
미수수익(신한)
```

## 7.2 카드거래

카드 결제에서 카드사는 채무의 거래처가 된다.

```text
복리후생비(판) 300,000 / 미지급금(국민) 300,000
```

- `복리후생비(판)`의 괄호: 비용의 소속
- `미지급금(국민)`의 괄호: 카드사 거래처

## 7.3 거래처명 표기 방식

수업자료에서는 보통 법인명 전체보다 핵심 명칭만 괄호에 적는다.

```text
㈜미금      → (미금)
신한은행    → (신한)
국민카드    → (국민)
현대해상    → (현대)
```

# 8. 대손충당금 뒤의 괄호

대손충당금의 괄호에는 `(판)`, `(제)`, `(영)`이 아니라 **어느 채권에 대한 충당금인지**가 들어간다.

| 표기 | 의미 |
|---|---|
| `대손충당금(외)` | 외상매출금에 대한 대손충당금 |
| `대손충당금(받)` | 받을어음에 대한 대손충당금 |
| `대손충당금(미수)` | 미수금에 대한 대손충당금 |
| `대손충당금(단기)` | 단기대여금에 대한 대손충당금 |

### 예시

```text
대손상각비(판) 3,500,000 / 대손충당금(외) 3,000,000
                              대손충당금(받)   500,000
```

이 분개에서 괄호의 의미는 다음과 같다.

- `대손상각비(판)`의 `(판)`: 판매와관리비 소속
- `대손충당금(외)`의 `(외)`: 외상매출금 대상
- `대손충당금(받)`의 `(받)`: 받을어음 대상

## 매출채권과 기타채권의 비용 구분

| 대상 채권 | 설정·부족분 비용 |
|---|---|
| 외상매출금·받을어음 | `대손상각비(판)` |
| 미수금·대여금·선급금 등 | `기타의대손상각비(영)` |

# 9. 예수금 뒤의 괄호

예수금의 괄호에는 원천징수하여 보관 중인 세금·공과금의 종류를 넣는다.

```text
예수금(근로소득세)
예수금(국민연금)
예수금(건강/장기요양)
예수금(고용보험)
예수금(사업소득세)
예수금(이자소득세)
```

## 시험 답안과 실무형 답안의 차이

수업자료는 다음 두 표기 수준을 구분한다.

### 시험형 단순 표기

```text
예수금 1,350,000
```

### 실무형 세목별 표기

```text
예수금(근로소득세) 450,000
예수금(국민연금) 500,000
예수금(건강/장기요양) 300,000
예수금(고용보험) 100,000
```

따라서 문제나 답안이 시험형인지 실무형인지에 따라 세목 괄호의 상세 수준이 달라질 수 있다.

# 10. 괄호를 항상 붙이는 것은 아님

자료의 모든 계정과목에 괄호가 붙는 것은 아니다.

일부 계정은 계정과목 자체로 성격이 구분되어 자료 답안에서 괄호가 주로 생략된다.

```text
급여
임금
잡급
전력비
가스수도료
이자비용
이자수익
광고선전비
기부금
```

다만 자료 안에서도 답안 상세 수준에 따라 표기가 혼용된다.

예를 들어 기초분개 답안에서는 본사 자동차보험료를 단순히 `보험료`라고 적은 사례가 있지만, 현재 상세 수업자료에서는 본사와 공장을 구분하여 `보험료(판)`, `보험료(제)`로 표시한다.

따라서 학습 사이트에서는 다음 두 층위를 구분하는 것이 안전하다.

1. **원문 답안**: 제공된 답안의 표기를 그대로 보존
2. **상세 학습 표기**: 현재 수업자료의 기준이 명확한 경우 `(판)`, `(제)`, `(영)`, 거래처 등을 함께 설명

# 11. 최종 판단 순서

분개를 작성할 때 아래 순서대로 판단한다.

## 1단계: 비용계정인가?

- 본사·영업부·관리부에서 발생 → `(판)`
- 공장·생산부에서 발생 → `(제)`
- 영업 외 활동에서 발생 → `(영)`

단, 다음 두 계정은 별도 기준을 확인한다.

- `수수료비용`: 발생 원인에 따라 `(제)`, `(판)`, `(영)` 모두 가능
- `기업업무추진비`: 매입거래처면 `(제)`, 매출거래처면 `(판)`

## 2단계: 채권·채무인가?

거래처가 제시되었는지 확인하고 괄호에 거래처명을 적는다.

```text
외상매출금(미금)
미지급금(국민)
단기차입금(신한)
```

## 3단계: 대손충당금인가?

어느 채권에 대한 충당금인지 표시한다.

```text
대손충당금(외)
대손충당금(받)
대손충당금(미수)
대손충당금(단기)
```

## 4단계: 예수금인가?

시험형 단순 표기인지, 실무형 세목별 표기인지 확인한다.

```text
예수금
예수금(근로소득세)
예수금(국민연금)
```

## 5단계: 정보가 부족한가?

문제에서 발생 장소, 거래처, 대상 채권, 세목이 제시되지 않았다면 괄호 내용을 임의로 만들어 넣지 않는다.

# 12. 한 줄 암기

> **비용은 “어디서 발생했나?” → 판·제·영**  
> **채권·채무는 “누구와 거래했나?” → 거래처**  
> **대손충당금은 “무슨 채권인가?” → 외·받·미수·단기**  
> **예수금은 “무엇을 공제했나?” → 세목**

# 13. Codex 반영용 구현 규칙

## 13.1 데이터 구조 권장안

```ts
type AccountAnnotation =
  | { type: 'cost_class'; value: '판' | '제' | '영' }
  | { type: 'counterparty'; value: string }
  | { type: 'allowance_target'; value: '외' | '받' | '미수' | '단기' | string }
  | { type: 'withholding_item'; value: string };
```

표시 문자열은 다음과 같이 생성한다.

```text
계정과목 + "(" + annotation.value + ")"
```

예시:

```text
보험료 + cost_class: 판           → 보험료(판)
미지급금 + counterparty: 국민     → 미지급금(국민)
대손충당금 + allowance_target: 외 → 대손충당금(외)
예수금 + withholding_item: 국민연금 → 예수금(국민연금)
```

## 13.2 자동 판정 시 주의사항

- 본사·영업부·관리부가 명시된 비용은 `(판)` 후보로 본다.
- 공장·생산부가 명시된 비용은 `(제)` 후보로 본다.
- 금융·투자 등 영업 외 활동의 수수료는 `(영)` 후보로 본다.
- 거래처가 없는 문제에서는 거래처 괄호를 임의 생성하지 않는다.
- 대손충당금의 괄호와 비용 소속 괄호를 같은 필드로 처리하지 않는다.
- 예수금은 시험형 합계 표기와 실무형 세목 표기를 별도 모드로 둔다.
- 원문 답안에 괄호가 생략되어 있더라도 원문 텍스트는 보존한다.
- 상세 학습 표기를 추가할 때는 현재 수업자료에서 근거가 명확한 경우에만 보완한다.
- 자료 간 표기가 충돌하면 자동 정규화하지 말고 검토 대상으로 표시한다.

## 13.3 UI 표시 권장안

```text
원문 답안: 보험료 480,000 / 현금 480,000
상세 표기: 보험료(판) 480,000 / 현금 480,000
설명: 본사 업무용 차량의 보험료이므로 판매와관리비
```

이 방식은 과거 기초 답안의 표기를 훼손하지 않으면서 현재 수업의 상세 구분을 함께 학습할 수 있게 한다.
